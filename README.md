# やることビュワー（todo-viewer）

**任意の GitHub リポジトリの Issues を、todoアプリ風に表示する小さなPWAです。**

「タスク管理は GitHub Issues でいい。でも見る・消し込む画面は普通のtodoアプリの顔がいい」という人のための道具です。

- データの正本は、あなたが指定したリポジトリの GitHub Issues。このページ自体にはタスクのデータも秘密情報も含まれません
- 対象リポジトリはアプリの設定から端末ごとに変更できます
- 外部ライブラリ不使用の素の HTML/CSS/JavaScript 1ファイル構成。通信先は GitHub API のみ

## 使い方

自分用に立てる場合は、このリポジトリを Fork して GitHub Pages を有効化すれば同じものが動きます。

### 初回設定（端末ごと）

1. 初回起動時に出る設定カード（または ⚙ の設定）で、対象リポジトリ（owner / repo）を指定する
2. GitHub で Fine-grained personal access token を発行する
   - https://github.com/settings/personal-access-tokens/new
   - Repository access: **対象リポジトリのみ**
   - Repository permissions: **Issues = Read and write**（Metadata は自動付帯）
3. アプリの初回画面にトークンを貼り付けて保存
   - トークンはその端末のブラウザ内（localStorage）にのみ保存され、GitHub API 以外へ送信されません


### 操作

- **追加**: 上部の入力欄から
- **完了**: 左の丸をタップ → Issue がクローズされます（直後は「元に戻す」が可能）
- **やったこと**: 左上のタイトル（やること ▾）をタップして「やったこと」に切り替えると、完了した項目が見られます。左の緑の丸をタップすると「やること」に戻せます
- **詳細**: タイトルをタップ → 本文と GitHub へのリンク
- 一覧は1つのフラットなリストで、古い順に表示されます（分類・絞り込み機能はありません）

### アプリとして置く

- **iPhone**: Safari で開く → 共有 → 「ホーム画面に追加」。単独アプリとして起動します
- **Windows**: Edge / Chrome で開く → アドレスバーのインストールアイコン（またはメニュー「アプリとしてインストール」）→ タスクバーやスタートにピン留めすると、小窓のウィジェット感覚で常駐できます

## 仕様メモ

- 一覧はオープンな Issue を最大100件取得（PR は除外）
- 前回表示した内容を端末内にキャッシュし、起動直後とオフライン時はそれを表示
- Service Worker はアプリ本体（シェル）のキャッシュのみ。API レスポンスはキャッシュしません
- 対象リポジトリとトークンは端末ごとの設定です。端末が変われば再設定してください
