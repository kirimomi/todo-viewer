設定

対象リポジトリ（この端末の設定）

対象は GitHub リポジトリの Issues です。変更すると、この端末の表示は新しいリポジトリの内容に切り替わります。 トークンの権限（対象リポジトリ）も合わせて変更してください。

アクセストークン（この端末の中だけに保存されます）

Fine-grained personal access token を想定しています。対象リポジトリは上の対象リポジトリのみ、 権限は Issues の Read and write だけに絞ってください。トークンはこの端末のブラウザ内に保存され、 GitHub の API 以外へは送信されません。

アプリの更新

表示が古いままのときは、キャッシュを消して最新版を読み直せます。対象リポジトリとトークンの設定は消えません。

設定ガイド（初回セットアップの手順）
  1. 対象リポジトリを決める：この設定画面の上の欄で owner / repo を設定します。タスクはこのリポジトリの Issues として保存されます。
  2. アクセストークンを発行する：GitHub の Fine-grained token の作成ページで、次の2つを設定します。
    • Repository access → Only select repositories で、対象リポジトリだけを選ぶ
    • Permissions → Repository permissions（折りたたまれているのでタップして開く）→ Issues: Read & Write にする（Metadata は自動で付きます）
  3. トークンをこのアプリに保存する：この設定画面のトークン欄に貼り付けます。保存先はこの端末のブラウザ内だけで、GitHub の API 以外に送信されません。
  4. アプリとして置く（任意）：スマホは共有メニューから「ホーム画面に追加」、PC はブラウザの「アプリとしてインストール」で単独のアプリとして起動できます。

困ったとき：読み込みや追加で 404 が出る場合は、トークンの Repository access に対象リポジトリが含まれていないサインです（権限のない非公開リポジトリには、GitHub が存在を隠すために 404 を返します）。"Public repositories" の選択では非公開リポジトリに届きません。401 / 403 の場合は、トークンが無効か、Issues の権限が不足しています。
